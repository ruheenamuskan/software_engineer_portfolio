# Ruheena Muskan Shaik — Software Engineer Portfolio

Personal portfolio website showcasing software engineering projects, technical skills, certifications, and experience.

## 🚀 Live Demo
- [Live Portfolio Website](https://ruheenamuskan.github.io/software_engineer_portfolio/)

## 🛠️ Tech Stack & Features
- **Frontend:** Responsive HTML5, Modern CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism, Ambient animations), Vanilla JavaScript
- **Sections:**
  - About & Bio
  - Core Skills & Proficiencies
  - Projects & Demos
  - Certifications
  - Experience & Education
  - Contact Information
- Fully responsive across mobile, tablet, and desktop devices
- Self-contained, lightweight, and fast loading

## 💻 Local Development
To view the portfolio locally:
1. Clone this repository:
   ```bash
   git clone https://github.com/ruheenamuskan/software_engineer_portfolio.git
   ```
2. Open `index.html` in your favorite web browser:
   ```bash
   open index.html # On macOS
   ```
